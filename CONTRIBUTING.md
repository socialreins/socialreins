# Contributing to SocialReins

Thanks for helping. SocialReins is early: the API server ([brain](https://github.com/socialreins/brain)) and the web app ([web](https://github.com/socialreins/web)) are being built now.

## Where things go

- Bugs and feature requests: open an issue in this repo with one of the templates. If you already know which repo it belongs to, open it there instead.
- Code changes: open a pull request in brain or web.
- Security problems: do not open an issue. Follow [SECURITY.md](SECURITY.md).

## Pull requests

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach before you spend time on it.
2. Keep each pull request to one change. Include tests for new behaviour.
3. Make sure the repo's checks pass locally (each repo's README lists them).
4. Describe what changed and why in the pull request body.
